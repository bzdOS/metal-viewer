PROTOCOL DETAILS

Zenoh Topic: bsdos/display/frame

Packet format (binary, big-endian integers):
┌────────┬────────┬────────┬──────────────────────────────────┐
│ Width  │ Height │ Stride │ RGBA32 Pixel Data               │
│ 4 bytes│ 4 bytes│ 4 bytes│ height × stride bytes           │
└────────┴────────┴────────┴──────────────────────────────────┘

Example (1280×720):
Offset  Type      Value          Description
  0     u32 BE    0x00000500     width = 1280
  4     u32 BE    0x000002D0     height = 720
  8     u32 BE    0x00001400     stride = 5120 (1280 × 4)
  12    u8[n]     [RGBA...]      pixel data (3,686,400 bytes)

Total size: 12 + 3,686,400 = 3,686,412 bytes

Data bandwidth (uncompressed):
  30fps @ 1280×720:   ~110 MB/s
  60fps @ 1280×720:   ~220 MB/s

LATENCY BREAKDOWN

VM → wf-recorder capture:        2-5ms
  (Wayland copy-free protocol)

screencopy-sender pack + send:  1-3ms
  (simple memcpy + Zenoh publish)

SSH tunnel transit:              5-15ms
  (network + encryption)

Metal texture upload:            10-20ms
  (GPU memory transfer, depends on GPU)

Render + present:                2-5ms
  (GPU rendering, CADisplayLink sync)
